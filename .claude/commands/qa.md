description: Ручной запуск агента qa-e2e на текущих изменениях — полный npm test + coverage:changed + sanity-чеки, отчёт о регрессиях. С исключением для нерантайм-изменений.
allowed-tools: Task, Read, Bash
---

Запусти субагента `qa-e2e` (`.claude/agents/qa-e2e.md`) на текущих изменениях в рабочем дереве.

Порядок:
1. Определи, что изменено (`git status --short`, `git diff --stat`).
2. Если изменения затрагивают только нерантайм-файлы (`.claude/**`, `.gitignore`, `docs/` без кода, конфигурация инструментария) и не трогают `src/**`/`src-ui/**`/`src/test/**` — примени **исключение для нерантайм-изменений**: полный `npm test`/`coverage:changed` НЕ запускаются, в отчёте `npm test: N/A`, проверяется только структура/текст/конфигурация и `npm run lint` если применимо.
3. Иначе — делегируй в субагента `qa-e2e` через Task: полный `npm test` один раз + `npm run coverage:changed` (100% по изменённым) + `npm run compile` + `npm run lint`. Флейк = дефект теста (возврат автору), не повод для повторов.
4. Верни отчёт: прошло/упало, покрытие изменённого, регрессии, кому вернуть.

`reviewer` после qa-e2e запускается отдельно командой `/review`.
